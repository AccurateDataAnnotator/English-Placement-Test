# ADA Advanced English Placement and Language Transfer Test

This repository hosts the interactive screening test designed to filter high caliber bilingual data annotators and language model evaluators. The assessment measures advanced linguistic expertise, critical instruction following capabilities, and natural language transfer skills.

## Key Features

*   Advanced Linguistic Screening: Tests syntax error detection, listening interpretation, and semantic comprehension.
*   Constraint Adherence Test: Includes a practical essay section with rigid structural and vocabulary constraints.
*   Bilingual Specialization Layer: Evaluates natural translation between English and Arabic to filter out mechanical or literal phrasing.
*   Responsive Frontend Design: Built as a single webpage featuring native right to left layout support for Arabic text blocks.

## Deployment

1. Place the index.html file in the root directory of your repository.
2. Push the code to GitHub.
3. Navigate to Settings, then Pages in your repository dashboard.
4. Select the main branch as the source and click Save to launch.
